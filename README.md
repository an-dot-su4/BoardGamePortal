# 🎲 ボドゲポータル

部屋番号を共有するだけで、友だちと 2〜8 人で遊べるブラウザボードゲーム集です。ログイン不要。

## 公開URL

- ポータル: https://an-dot-su4.github.io/BoardGamePortal/
- 天下札のカード一覧: https://an-dot-su4.github.io/BoardGamePortal/games/tenka/gallery.html

## 遊び方

1. 名前を入れて、遊びたいゲームの「部屋を作る」を押す（あなたがホストになります）
2. 表示された 4 文字の部屋番号か招待リンクを友だちに送る
3. 友だちは部屋番号を入れて参加。そろったらホストが「ゲーム開始」

ホストのブラウザが進行役です。ホストはなるべく Wi-Fi で、ゲーム中はページを閉じないでください。
切れてしまっても、同じブラウザで同じ部屋を開き直せば続きから再開できます（参加者は自動で戻ります）。
参加者が別の端末に乗り換えたときは、同じ名前で入れば元の席に戻れます。

## 仕組み

- GitHub Pages で配信する静的サイト。サーバーはありません。
- 参加者同士は WebRTC（[Trystero](https://github.com/dmotz/trystero)）で直接つながります。最初に相手を見つけるときだけ公開の Nostr リレーを使います。
- 一部のネットワーク（会社のネットワークや一部のモバイル回線）ではつながらないことがあります。

## 開発

```bash
npm test                 # ルールのテスト
npm install && npm run e2e   # ブラウザで5人分の通し確認（大富豪・嵐の航海・共通部分）
npm run e2e:games        # 追加ゲームのブラウザ通し確認（SHOTS=dir でスクショ、MOBILE=1 でスマホ幅）
npm run serve            # http://localhost:8080/?local=1 を複数タブで開くと1台で複数人プレイ
```

ゲームの追加方法は `CLAUDE.md` と `.claude/skills/add-game/SKILL.md` を参照。
